# CCTV · 정보통신 견적 계산기

현장에서 바로 계산하고, 그대로 고객에게 보내는 **CCTV·정보통신 시공 견적 계산기**입니다.
설치 없이 브라우저에서 열리는 단일 페이지 앱이며, 휴대폰 화면에 맞춰 만들었습니다.

**바로 쓰기 →** https://myc8101-cmyk.github.io/cctv/

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 빠른 품목 프리셋 | 실외·실내 IP 카메라, NVR, PoE 스위치, 보안용 HDD, 케이블·배관 부자재, 공임 등 원터치 추가 + 빈 행 직접 추가 |
| 실시간 계산 | 수량 × 판매단가 = 금액, 공급가액·부가세(10%)·최종 합계 자동 계산 |
| 부가세 처리 | **별도 / 포함** 토글. 포함 모드에서는 총액에서 부가세를 역산합니다 |
| 단수 절사 | 절사 없음 / **천원 절사** / **만원 절사** (공급가액 기준, 부가세는 절사된 금액으로 재계산) |
| 내부 마진 | 품목별 매입원가를 넣으면 총 원가·마진·마진율(%)을 즉시 표시. **인쇄·복사에는 절대 포함되지 않음** |
| 원가 숨기기 | 화면에서 원가·마진을 감추는 스위치 (고객에게 화면을 보여줄 때) |
| 카톡 요약 복사 | 품목·금액·일금 한글 표기까지 정리된 텍스트를 클립보드로 복사 |
| 인쇄 / PDF | A4 한 장 견적서로 인쇄. 모바일에서는 'PDF로 저장' |
| 자동 임시저장 | 입력 즉시 브라우저(`localStorage`)에 저장, 초기화 버튼 제공 |
| 한글 금액 | 합계를 "일금 ○○○원정" 형태로 자동 표기 |

## 사용법

1. **견적 정보**에 현장·고객명, 견적일을 입력합니다. 발행자 정보는 선택이며 인쇄에만 표시됩니다.
2. 품목 버튼을 눌러 항목을 추가하고 **판매단가**를 입력합니다. 수량은 −/+ 버튼으로 조정합니다.
3. 부가세 처리와 단수 절사를 고르면 합계가 바로 바뀝니다.
4. **카톡 요약 복사**로 문자·카톡에 붙여널거나, **인쇄 / PDF**로 견적서를 출력합니다.

## 데이터 보관

- 작성한 견적, 품목별 매입원가, 발행자 정보는 **사용자의 브라우저(localStorage)에만** 저장됩니다.
  서버로 전송되지 않고, 이 저장소에도 들어 있지 않습니다.
- 같은 브라우저·같은 주소로 열면 이전에 쓰던 견적이 그대로 이어집니다.
- 브라우저 데이터를 지우거나 '초기화'를 누르면 삭제됩니다.

## 구성

```
index.html            앱 전체 (HTML + CSS + JS 단일 파일)
manifest.webmanifest  홈 화면에 추가할 때 쓰는 설정
icon.svg              앱 아이콘
```

## 수정하기

`index.html` 하나만 고치면 됩니다. 품목 프리셋과 세트 구성은 파일 안 `PRESETS`, `SETS` 배열에서
바꿀 수 있습니다.

```js
var PRESETS = [
  { name: '실외 IP 카메라 (4MP 불릿)', short: '실외 IP 카메라', spec: '4MP 불릿 · 대' },
  ...
];
```
