# CCTV 설치·수리 예상 견적 계산기

CCTV를 처음 설치하거나 고장 수리할 때 **대략 얼마인지 클릭 몇 번으로 확인하는 소비자용 예상 견적기**입니다.
설치 없이 브라우저에서 열리는 단일 페이지 앱이며, 휴대폰 화면에 맞춰 만들었습니다.
최종 금액은 현장 실사 후 확정됩니다.

**바로 쓰기 →** https://myc8101-cmyk.github.io/cctv/

## 이렇게 씁니다 (클릭 3번)

1. 맨 위에서 **🛠️ 신규 설치 예상** 또는 **🔧 고장 수리 예상**을 고릅니다. 두 견적은 따로 계산됩니다.
2. **① 카메라 세트**를 한 번 누르면 카메라·녹화기·HDD·출장료가 한 번에 담깁니다.
   (아날로그 4대·8대 / IP 4대·8대 / 혼합 4대 — 버튼에 구성과 금액이 함께 보입니다)
3. **② 우리 매장·집 평수**를 누르면 기본 10m를 넘는 배선이 자동으로 계산됩니다.
4. **③ 더 담기**를 열면 카메라·녹화기·HDD를 하나씩 골라 담을 수 있습니다.
   수리 탭에서는 배선 수리·아답터·카메라 교체·녹화기·HDD 항목이 바로 보입니다.
5. 아래 **예상 견적 합계**에서 부가세 별도/포함을 고르고 **예상 견적 복사**로 카톡·문자에 붙여넣습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 설치 / 수리 분리 | 신규 설치와 고장 수리는 품목·부가세·절사·인쇄가 완전히 따로 계산됩니다 |
| 세트 한 번에 담기 | 아날로그 4·8대, IP 4·8대, 혼합 4대 — 카메라·녹화기·HDD·출장료가 한 번에 담기고 금액이 미리 보입니다 |
| 평형별 추가 배선 | 30평 이하 ~ 81평 이상 5단계. 카메라 대수 × 대당 추가 m를 자동 계산(1m당 3,000원) |
| 기본 출장료 | 50,000원이 처음부터·모든 세트에 포함됩니다 |
| 품목 조절 | 담긴 품목은 수량(−/+)만 만지면 됩니다. 단가는 '단가 바꾸기'를 눌렀을 때만 열립니다 |
| 실시간 계산 | 수량 × 판매단가 = 금액, 공급가액·부가세(10%)·최종 합계 자동 계산 |
| 부가세 처리 | **별도 / 포함** 토글. 포함 모드에서는 총액에서 부가세를 역산합니다 |
| 단수 절사 | 절사 없음 / **천원 절사** / **만원 절사** (공급가액 기준, 부가세는 절사된 금액으로 재계산) |
| 예상 견적 복사 | 품목·금액·일금 한글 표기까지 정리된 텍스트를 클립보드로 복사 |
| 인쇄 / PDF | A4 한 장 견적서로 인쇄. 모바일에서는 'PDF로 저장'. 현장·고객명 등 상세 정보는 접힌 '상세 견적서 정보'에서 입력 |
| 자동 임시저장 | 입력 즉시 브라우저(`localStorage`)에 저장, '처음부터' 버튼으로 초기화 |
| 한글 금액 | 합계를 "일금 ○○○원정" 형태로 자동 표기 |

## 데이터 보관

- 작성한 견적과 상세 견적서 정보는 **사용자의 브라우저(localStorage)에만** 저장됩니다.
  서버로 전송되지 않고, 이 저장소에도 들어 있지 않습니다.
- 같은 브라우저·같은 주소로 열면 이전에 쓰던 견적이 그대로 이어집니다.
- 브라우저 데이터를 지우거나 '처음부터'를 누르면 삭제됩니다.

## 구성

```
index.html            앱 전체 (HTML + CSS + JS 단일 파일)
manifest.webmanifest  홈 화면에 추가할 때 쓰는 설정
icon.svg              앱 아이콘
```

## 수정하기

`index.html` 하나만 고치면 됩니다. 품목 단가·세트 구성·수리 항목은 파일 안 `PRESETS`, `SETS`,
`REPAIR_GROUPS` 에서 바꿀 수 있습니다.

```js
var PRESETS = {
  install: [
    { name: 'IP 2MP 야간컬러(F1.0) 실내/기본', short: 'IP 실내/기본', spec: '2MP 야간컬러 F1.0 · 대', price: 180000, cam: true },
    ...
  ],
  ...
};
```
